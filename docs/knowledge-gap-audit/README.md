# Knowledge-gap audit reports

The audit these reports describe (`knowledge_audit/`, its page, scripts and
settings) was removed in step 25 and replaced by the knowledge-coverage check in
`coverage_check/`. The A1–A6 reports, the readiness logs and the runbooks are kept
as history; the commands, settings and routes they name no longer exist.

P1 to P4 still describe live retrieval behaviour:

- `P1_RRF_REPORT.md`: reciprocal rank fusion.
- `P2_RETRIEVAL_DEPTH_REPORT.md`: configurable retrieval candidate depths.
- `P3_RERANKER_BATCHING_REPORT.md`: sequential reranker batching.
- `P4_KB_TAXONOMY_REPORT.md`: FAQ taxonomy preservation.
